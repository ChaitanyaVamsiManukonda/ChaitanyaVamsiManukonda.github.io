AI Chat Interface

Recent Project

Executive Summary

A web-based interface for interacting with OpenAI and Anthropic AI models, designed to be deployed on GitHub Pages with Netlify Functions for backend support. It features a complete chat UI with support for RAG (Retrieval-Augmented Generation) training via voice input.

Features

  • Support for both OpenAI and Anthropic (Claude) APIs
  • Model selection and Image upload capability
  • Chat history with message threading
  • Responsive design that works on mobile and desktop
  • Voice-triggered RAG training: Record audio, transcribe it, and train the RAG model with your voice input.

Microphone / Voice recording & RAG Training

This project includes a simple microphone recorder in the chat UI with integrated RAG training. Features:

  • Record audio from your browser (click the 🎤 button).
  • Live speech-to-text (Web Speech API) in supporting browsers — transcribe as you speak.
  • Play back and download recorded audio.
  • Train RAG with transcript — after recording, click "📚 Train RAG with transcript" to add your transcript to the retrieval index.
  • Send audio to server for processing and optional cloud transcription.

Voice-to-RAG Training Workflow

  1. Click 🎤 to start recording audio. Speak naturally into your microphone.
  2. Stop recording when done.
  3. After recording, choose to Insert transcript, Train RAG with transcript, or Send audio.
  4. Your transcript is now indexed and will be retrieved when relevant queries are asked.

Setup & Technical Details

Project Structure: Includes HTML, vanilla JS, and serverless Netlify functions.

RAG Index Management: The retrieval index is stored locally and accessed via serverless endpoints. Query with retrieval: If no LLM API keys are configured, zero-cost retrieval provides top-K documents.

Security: API keys are securely stored as environment variables in Netlify and processed through a secure proxy (Netlify Functions) over HTTPS.

Privacy: Audio is recorded locally. Transcripts are added to a local JSON index and not sent to external services unless explicitly enabled.
